# Advisory review, 2026-11-16

Findings from the Fable review of `docs/proposal.md` that change the proposal. The phase plan it produced is in `phases.md`.

## Blocking

- No TTS provider on AI Gateway is ZDR. ElevenLabs, Fish Audio and Google AI Studio are missing from the ZDR provider table, so speech requests with `zeroDataRetention` set should fail (inferred from docs, not run). Fix: scripts carry public news only; no project aliases or keys spoken or in titles. The privacy section must change before any public claim.
- cvzx `src/app/api/podcast/audio/[token]/[file]/route.ts` serves any episode id for any valid feed token. Fine single-user, a cross-user leak here. Scope the lookup by the token's user when porting.

## Other

- Vercel Workflow records every step input and output. Steps pass ids only, or the "never log scripts or context" rule and the 24 hour purge break.
- Claude Fable is not ZDR, and provider-side web search is outside ZDR.
- Cost model: TTS figures match live Gateway prices. The $2.50 LLM figure assumes one pass over cached briefs, while today's quality comes from a long agentic research run. Shared research only saves money where stacks overlap, so the 20 to 25 subscriber break-even is optimistic. Trials (about $1.25 each) and sales tax are unmodeled.
- `push_context`: allowlist registry-validated package names instead of rejecting code-like payloads.
- MCP output carries web-derived text into agents with shell access: return structured fields only.
- ffmpeg on Functions is unverified: spike it in phase 1 or use single-call multi-speaker TTS.
- Do not run other people's episodes on Isaac's Claude subscription login; use API billing.

- Rewrite: `store.ts` and migrations 013/014 (`published_on` unique becomes `(user_id, published_on)`).
- Phase 0 only: `tools/podcast/run.mjs`. Keep its TTS retry, hash-keyed clip cache, `previous_text`/`next_text` and ffmpeg graph (0.3s/0.15s gaps, loudnorm -16) as phase 1 steps; drop the lock, heartbeat, prune and Claude spawn. Keep the sourcing rules, "write for the ear" block and JSON contract from `tools/podcast/prompt.md`.
